# Project Assumptions

1. All data is synthetic and created only for portfolio demonstration.
2. Case identifiers do not represent real case numbers.
3. Location and region names are mock categories.
4. Workflow stages are generalized and do not represent any specific agency process.
5. Processing time is calculated as the difference between received date and closed date for closed cases.
6. For open cases, processing time is calculated as the difference between received date and the current date.
7. Missing stage end dates indicate stages that are still active or incomplete.
8. The project is designed to demonstrate SQL analytics, not to represent real public justice outcomes.
9. The sample data is intentionally small so that the project structure and SQL logic are easy to review.
10. The same design could be scaled to larger operational datasets in a real analytics environment.
